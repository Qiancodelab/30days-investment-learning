# Market30｜30 天投資學習平台

這是一個可公開部署的多人前端版本。

## 現有功能
- 30 天循序學習課程
- 每日任務打勾
- 每日反思筆記
- 個人 Dashboard
- 連續學習天數
- 五階段進度
- 30 天快速跳轉
- 市場三大主題／觀察產業／不買清單
- 匯出個人學習紀錄
- 清除個人資料
- RWD：手機／平板／桌機
- 每個使用者在自己的瀏覽器有獨立 localStorage 資料

## 公開部署
這版是純 HTML/CSS/JS 靜態網站，可以部署到 GitHub Pages、Cloudflare Pages、Netlify 或 Vercel。

## 如果要做真正的「平台版」
下一階段可接：
1. Supabase / Firebase 帳號登入
2. 雲端同步學習進度
3. 使用者個人 Profile
4. 公開排行榜與連續打卡
5. 每日市場資訊 API
6. AI 自動摘要每日 5 篇資訊
7. 個股研究卡資料庫
8. 社群討論／共學小組
9. 管理員後台
10. 內容管理 CMS

注意：目前版本沒有伺服器與帳號系統；「多人使用」是指任何人都可以打開網站並擁有自己的瀏覽器進度。
